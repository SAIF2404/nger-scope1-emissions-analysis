# NGER Corporate Scope 1 Emissions Analysis
An independent Power BI portfolio project exploring published corporate Scope 1 greenhouse gas emissions from 2021–22 to 2023–24.

## Purpose

Present emissions trends, sector comparisons and the concentration of reported emissions in a clear, accessible format.

## Report contents

- **Overview:** Headline indicators, sector breakdown and annual emissions trend.
- **Trends:** Sector-level changes across reporting years.
- **Top Emitters:** Comparison of selected corporations by Scope 1 emissions.
- **Insights:** Interpretation, coverage limitations and verification requirements.

## Tools

Microsoft Power BI Desktop.

## Data source

Australian Clean Energy Regulator — [NGER reporting data and registers](https://cer.gov.au/markets/reports-and-data/nger-reporting-data-and-registers).

## Files

- [Power BI report](NGER_Scope1_Analysis.pbix) — download and open in Power BI Desktop.
- [PDF preview](NGER_Scope1_Analysis.pdf) — view the report without Power BI.

## Data quality and limitations

The report covers published NGER corporate data, rather than all Australian emissions. The reporting population may change between years, so aggregate changes should not be interpreted as like-for-like emissions reductions.

Displayed trends have been checked for consistency with the imported annual totals. Independent reconciliation against the original CER publications remains outstanding, including corporation counts, top-20 rankings and concentration figures.

## Project status



This is an independent project and is not an official Clean Energy Regulator report.
